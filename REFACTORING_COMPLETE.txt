================================================================================
                        ADDING NEW PAGES (EASY!)
================================================================================

To add a new page, follow this simple process:

STEP 1: Create new module file
File: modules/my_new_page.py

  from tkinter import tk

  class MyNewPage:
      def __init__(self, parent, admin):
          self.parent = parent
          self.admin = admin
          self.build()
      
      def build(self):
          # Build your UI here
          tk.Label(self.parent, text="My New Page").pack()

STEP 2: Import in dashboard.py
  from .my_new_page import MyNewPage

STEP 3: Add to page router
  elif key == "my_new_page":
      MyNewPage(self.content_frame, self.admin)

STEP 4: Add to sidebar menu (optional)
  ("my_new_page", "My New Page", "icon"),

DONE! Your new page is now integrated.
