================================================================================
                          HOW TO USE
================================================================================

FOR END USERS:

1. Run HallmarkPro
   $ python main.py

2. On Login Page, click "🏛 Register Centre"

3. Fill Registration Form
   - Firm Name: Enter your business name
   - Full Name: Your name
   - Phone: 10-digit mobile number
   - Email: Your email address
   - Address: Business address (optional)
   - State: Select from dropdown
   - Firm Type: Select business type
   - Password: Create password (6+ chars)
   - Logo: Upload round firm logo (PNG/JPG)

4. Click "🏛 Create Account"

5. Success! Return to login with:
   - Username: Your phone number
   - Password: Your registered password

FOR DEVELOPERS:

Access Logo Location:
  /vercel/share/v0-project/assets/logos/{phone_number}_logo.png

Query Registered Firms:
  from db.schema import get_connection
  conn = get_connection()
  c = conn.cursor()
  c.execute("SELECT * FROM firms WHERE created_at > datetime('now','-1 day')")
